# Product Context

This file contains the high-level overview, goals, features, and architecture of the project.

## Project Overview
ByteComposition is an audio processing and composition web application that combines audio synthesis, analysis, and real-time processing capabilities.

## Core Components
1. Frontend (Web Interface)
   - Audio processing and visualization
   - Real-time spectral analysis
   - Buffer manipulation and composition
   - Worklet-based audio processing

2. Sample Server
   - Next.js based backend
   - Sample management and delivery
   - Random sample selection API
   - Buffer processing endpoints

## Key Features
- Real-time audio analysis and visualization
- Audio worklet processors for efficient processing
- Integration with Freesound.org API
- Spectral visualization capabilities
- Byte-step audio processing
- Frequency array synthesis
- Dynamic buffer management

## Technical Architecture
- Frontend: Vanilla JavaScript with Web Audio API
- Backend: Next.js server for sample management
- Build System: Webpack with custom configuration
- Deployment: Automated deployment to tritton.uberspace.de
